OrchMerge

N-to-1 note merge — Bitwig has no reliable native way to do this, so this pair does it instead.
feeds OrchPiano's Reduce building Omrg

OrchPiano's Reduce mode needs to see every orchestral track's notes at once. OrchMerge is a Sender/Hub pair — drop a Sender on every track (transparent pass-through, never alters that track's own signal), one Hub on OrchPiano's own input, and the Hub emits one genuinely merged stream.

Not fully settled yet. A phantom-note bug (an idle Sender with no clip on its track was confirmed transmitting a real note to the Hub) is a known, open, unroot-caused issue — see the project's own notes before trusting a take with an idle Sender in the rig. Phase 3's jitter-absorbing emit buffer is built and code-reviewed but not yet confirmed live. This guide documents the real controls as they exist now, not a claim that the plugin is finished.
